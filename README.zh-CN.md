Time to Walk 是一款为长时间伏案办公或学习的人设计的轻量久坐提醒插件。选择一段
专注时间，计时结束后，全屏页面会提醒你站起来。没有需要维持的连续记录，也没有
必须完成的运动目标。

站起来，哪怕只有一秒，也算一次胜利。

## 为什么做它

大多数休息提醒很容易被无意识地关掉；另一些工具又把简单的活动变成了需要管理的
新任务。我想做一个更温和的中间方案：在正确的时刻明确打断，并加入刚刚好的阻力，
让“要不要继续坐着”变成一次有意识的选择。

## 主要功能

- 15、25、30、45 或 60 分钟专注计时
- 全屏起身提醒
- 提前关闭需要点击三次，减少下意识跳过
- 5 分钟后自动关闭提醒并开始下一轮
- 可选的接水、拉伸、远眺或走动建议
- 两套可随时切换的视觉主题
- 自然友好的中英文提醒
- 设备锁定时自动暂停
- 浏览器中断后自动恢复计时

## 关键产品判断

- **活动不等于完成任务。** 不打卡、不设置目标、不维护连续记录，也不追踪运动。
- **增加阻力，但保留出口。** 三次点击让提前关闭变成有意识的决定，同时提醒仍会
  自动结束。
- **默认只在本地运行。** 无需账号，不使用数据分析，也不收集个人信息；计时状态
  和偏好只保存在浏览器中。
- **让计时足够可靠。** 使用持久化截止时间和 Chrome Alarm，避免扩展后台被挂起
  后意外延长倒计时。

## 技术概览

- Chrome Extension Manifest V3
- 原生 HTML、CSS 与 JavaScript
- `chrome.alarms`、`chrome.storage`、`chrome.windows` 与 `chrome.idle`
- Node.js 内置测试运行器
